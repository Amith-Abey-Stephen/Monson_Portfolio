Cloudflare Storage & Bindings

Verify Cloudflare KV and R2 connections or configure custom endpoints.

This portfolio is configured to sync directly with Cloudflare KV (for live structured content) and Cloudflare R2 (for image uploads) via Cloudflare Pages Functions (/api/content & /api/upload).

☁️ Cloudflare Pages KV Binding:
KV Namespace Binding: PORTFOLIO_KV
Environment Variable (Password): ADMIN_PASSWORD
🪣 Cloudflare R2 Bucket Binding:
Bucket Binding: PORTFOLIO_R2
Public Domain / CDN: R2_PUBLIC_URL (Optional, fallback returns direct API URL)
